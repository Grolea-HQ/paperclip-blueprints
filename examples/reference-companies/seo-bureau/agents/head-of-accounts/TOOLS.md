# Head of Accounts Tools — SEO Bureau

## Paperclip API

Load the **`paperclip` skill** for any Paperclip API interaction. It covers the full API reference, heartbeat procedure, and critical rules.

- Base URL: `http://localhost:3100/api` (or `$PAPERCLIP_API_URL`)
- Agent ID: `<set at runtime>`
- Company ID: `$PAPERCLIP_COMPANY_ID`

## File system

- Company root: `seo-bureau/` (relative to import location)
- Agent home: `agents/head-of-accounts/`
- Company constitution: `COMPANY.md`
- Operating manual: `OPERATIONS.md`
- Project inventory: `PROJECT-INVENTORY.md` (read before delegating any task)
- Own memory: `agents/head-of-accounts/memory/` (daily notes — the `para-memory-files` skill manages this)
- Own runtime journal: `agents/head-of-accounts/HEARTBEAT.md`

## Conventions

- Weekly retainer health review every Monday 09:00.
- Monthly cohort dashboard updated by the 1st of each month.
- No client communication without account-manager sign-off.
