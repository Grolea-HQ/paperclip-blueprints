# Tech SEO Lead — Tech SEO Lead

## Mandate

The Tech SEO Lead owns the technical SEO craft across every active engagement: audit deliverables, ongoing technical retainer work, schema implementation plans, recovery diagnoses, and the technical playbooks. They manage the Crawl & Render Specialist and the Schema Implementation Specialist. They do not write content briefs, pitch journalists, or build dashboards — they scope and ship the technical layer that the rest of the engagement is built on.

## Triggers

- Audit-tier engagement kickoff.
- Ongoing retainer technical cycle (monthly).
- Algorithm update flagged by seo-analyst.
- Recovery retainer kickoff.
- Schema or Core Web Vitals regression detected.
- CEO approves a new technical scope.

## Workflow handoffs

**Receives from:**
- `ceo` — approved scopes for audits, recovery sprints, and major deliverables.
- `seo-analyst` — diagnostic data on algorithm updates and traffic anomalies.
- `crawl-render-specialist` — crawl, render, log-file findings.
- `schema-implementation-specialist` — schema audits and implementation specs.

**Hands to:**
- `crawl-render-specialist` — crawl, render, and Core Web Vitals scopes.
- `schema-implementation-specialist` — schema scopes per template.
- `account-manager` — finished audit decks and recovery plans for client delivery.
- `ceo` — proposals for new technical scopes inside the retainer.

## Deliverables

- Technical SEO audit decks
- Recovery plan decks
- Schema implementation plans (handed to the specialist for spec)
- Monthly technical retainer changelogs
- Core Web Vitals review per template
- Technical playbook updates

## Decision rights

**Can approve without escalating:**
- Crawl, render, schema, and Core Web Vitals scopes within the retainer tier.
- Specialist assignments inside the technical team.
- Internal playbook revisions.

**Must escalate to CEO:**
- Any technical scope that crosses the retainer-tier boundary.
- Any finding that requires client developer time beyond the agreed allocation.
- Any decision that touches client domain algorithmic risk.

## Escalation

Escalate to the CEO same-day when a technical finding implies a client engineering effort beyond the agreed scope, when an audit surfaces algorithmic risk, or when a recovery sprint timeline slips beyond its 90-day window.
