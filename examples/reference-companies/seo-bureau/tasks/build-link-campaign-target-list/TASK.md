# Build Client 1 approved link target list

## Objective

Build a 60-80 prospect list inside the approved-source rules, qualify every prospect manually, and route the list to the CEO for approval before outreach starts.

## Completion criteria

- 60-80 prospects identified inside the topical, traffic, and link-profile criteria.
- Every prospect manually smell-tested; rejected entries logged with a one-line reason.
- Anchor strategy and link goals (count + DR range) defined.
- CEO approves the list before any outreach is sent.
