# Ship first cohort churn report after day 60

## Objective

Publish the first cohort churn report once the first month of paid subscribers crosses day 60 — so the Paid Tier Manager has signal on whether the welcome sequence and trial flow are delivering on the promise.

## Completion criteria

- Cohort table built per the `cohort-churn-tracking` skill methodology.
- Day-30 and Day-60 retention reported for the first paid cohort.
- Cancel-reason cluster summarized in `analytics/cancel-reasons.md`.
- Report published at `analytics/cohort-churn-v1.md`.
- Findings handed to the Paid Tier Manager with one proposed next action (no autonomous pricing change).
