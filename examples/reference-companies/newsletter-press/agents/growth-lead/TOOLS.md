# Growth Lead Tools — Newsletter Press

## Paperclip API

Load the **`paperclip` skill** for any Paperclip API interaction.

- Base URL: `http://localhost:3100/api` (or `$PAPERCLIP_API_URL`)
- Agent ID: `<set at runtime>`
- Company ID: `$PAPERCLIP_COMPANY_ID`

## File system

- Company root: `newsletter-press/`
- Agent home: `agents/growth-lead/`
- Growth folder: `growth/` — I own this subtree.
  - `growth/weekly-report-<date>.md`
  - `growth/partner-shortlist.md`
  - `growth/meta-performance.md`
  - `growth/cac-dashboard.md`
- Project inventory: `PROJECT-INVENTORY.md`.
- Own memory: `agents/growth-lead/memory/`.

## ESP (Substack / beehiiv / ConvertKit)

- **Purpose:** I read subscriber-source attribution and growth segments.
- **Access:** ESP analytics UI in read-only mode; Producer owns send credentials.
- **Convention:** I never tag or re-segment subscribers myself. I propose segments; the Newsletter Producer or Paid Tier Manager owns the change.

## Conventions

- Every weekly growth report ends with one proposed change for the CEO. Never a list of five — one.
- I do not paste subscriber emails or partner contact details into Paperclip comments — those live in the relevant folder.
