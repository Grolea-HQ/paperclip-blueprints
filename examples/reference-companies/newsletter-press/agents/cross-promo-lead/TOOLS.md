# Cross-Promo Lead Tools — Newsletter Press

## Paperclip API

Load the **`paperclip` skill** for any Paperclip API interaction.

- Base URL: `http://localhost:3100/api` (or `$PAPERCLIP_API_URL`)
- Agent ID: `<set at runtime>`
- Company ID: `$PAPERCLIP_COMPANY_ID`

## File system

- Company root: `newsletter-press/`
- Agent home: `agents/cross-promo-lead/`
- Growth subtree: `growth/cross-promo-pipeline.md`, `growth/cross-promo-log.md`, `growth/cross-promo-templates.md`.
- Project inventory: `PROJECT-INVENTORY.md`.
- Own memory: `agents/cross-promo-lead/memory/`.

## SparkLoop

- **Purpose:** Discover and run cross-newsletter recommendations.
- **Access:** Web UI; credentials owned by the Founder, configured by the Newsletter Producer.
- **Convention:** Every accepted partner gets a row in `growth/cross-promo-pipeline.md` with their open rate, list size, and niche-fit score before the swap goes live.

## beehiiv Boosts

- **Purpose:** Source paid-boost partners (if our ESP is beehiiv) or competitive intelligence on partner rates (if our ESP is Substack or ConvertKit).
- **Access:** Web UI in the chosen ESP.
- **Convention:** I never trigger a boost spend on my own; the Growth Lead and CEO approve the budget envelope.

## Conventions

- Every swap proposal includes partner open rate, list size, niche-fit score, projected subs gained, and an outreach-sent date.
- I never paste partner contact details into Paperclip comments — those live in `growth/cross-promo-pipeline.md`.
