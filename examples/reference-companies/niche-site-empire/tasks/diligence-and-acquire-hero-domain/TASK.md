# Diligence and acquire hero site domain

## Objective

Run the full domain diligence checklist on candidate domains for the hero site, produce a buy / pass recommendation for the CEO, and execute the acquisition once approved.

## Completion criteria

- Diligence report filed: Wayback history, Whois, link profile, toxic-link ratio, manual-action check, niche fit.
- Buy / pass recommendation written for CEO.
- CEO approval received in writing for purchases over $500.
- Domain acquired and handoff package delivered to technical-seo-lead within 24 hours of purchase.
