# Affiliate Disclosures Compliance Tools — Niche Site Empire

## Paperclip API

Load the **`paperclip` skill** for any Paperclip API interaction. It covers the full API reference, heartbeat procedure, and critical rules.

- Base URL: `http://localhost:3100/api` (or `$PAPERCLIP_API_URL`)
- Agent ID: `<set at runtime>`
- Company ID: `$PAPERCLIP_COMPANY_ID`

## File system

- Company root: `niche-site-empire/` (relative to import location)
- Agent home: `agents/affiliate-disclosures-compliance/`
- Company constitution: `COMPANY.md`
- Operating manual: `OPERATIONS.md`
- Project inventory: `PROJECT-INVENTORY.md` (read before delegating any task)
- Own memory: `agents/affiliate-disclosures-compliance/memory/` (daily notes — the `para-memory-files` skill manages this)
- Own runtime journal: `agents/affiliate-disclosures-compliance/HEARTBEAT.md`

## Conventions

- Portfolio disclosure standard lives at `portfolio/disclosure-standard.md` and is the source of truth.
- Per-article clearance log lives under each site's `editorial/disclosure-log.md`.
- Quarterly compliance audit reports go to content-director on the last Friday of the quarter.
