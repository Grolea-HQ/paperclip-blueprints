# CEO / Portfolio Owner Tools — Niche Site Empire

## Paperclip API

Load the **`paperclip` skill** for any Paperclip API interaction. It covers the full API reference, heartbeat procedure, and critical rules.

- Base URL: `http://localhost:3100/api` (or `$PAPERCLIP_API_URL`)
- Agent ID: `<set at runtime>`
- Company ID: `$PAPERCLIP_COMPANY_ID`

## File system

- Company root: `niche-site-empire/` (relative to import location)
- Agent home: `agents/ceo/`
- Company constitution: `COMPANY.md`
- Operating manual: `OPERATIONS.md`
- Project inventory: `PROJECT-INVENTORY.md` (read before delegating any task)
- Own memory: `agents/ceo/memory/` (daily notes — the `para-memory-files` skill manages this)
- Own runtime journal: `agents/ceo/HEARTBEAT.md`

## Conventions

- Portfolio P&L is read every Monday before any other report.
- Kill-list verdicts are recorded in writing in the monthly review log.
- Founder escalations go via written memo, never verbal — and always include a recommendation.
- All site-acquisition approvals are linked to the diligence report in PROJECT-INVENTORY.md.
