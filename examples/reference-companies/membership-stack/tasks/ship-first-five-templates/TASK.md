# Ship first five templates into library

## Objective

Build, QA, and release the first five templates into the library, each following the Template Design Standards skill — with example pre-filled versions, cover sheets, inline instructions, and INDEX.md plus release-notes.md per asset.

## Completion criteria

- Five templates live under library/templates/<category>/<asset-slug>/
- Each template has INDEX.md, release-notes.md, an example pre-filled version, and a cover sheet
- Each template passes the QA checklist (incognito open, timed fill-in, instructions cold-read)
- Product Manager has reviewed; CEO has approved each release
