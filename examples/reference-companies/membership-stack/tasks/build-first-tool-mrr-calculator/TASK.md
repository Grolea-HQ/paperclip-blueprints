# Build first lightweight tool: MRR impact calculator

## Objective

Scope, build, and ship the first lightweight tool — a stateless MRR impact calculator that estimates the MRR shift from a proposed pricing or churn change — into the Week-3 release slot.

## Completion criteria

- Tool live on an approved managed host (Vercel / Apps Script / Notion / Cloudflare Pages)
- Stateless: no member data persisted server-side
- Time-to-result for a member under 60 seconds from open
- INDEX.md, release-notes.md, and maintenance note with next-refresh date filed
- Product Manager reviewed; CEO approved the release
