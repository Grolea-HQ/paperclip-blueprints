# Build ICP document and target list of 50 SMB prospects

## Objective

Define the agency's ICP (SMB segments served, sub-segments declined, ideal retainer profile) and assemble a research-backed target list of 50 prospects with named decision-makers. Output supports the CEO's outbound conversations and the Discovery Call Playbook qualification thresholds.

## Completion criteria

- ICP document filed at agents/strategist/memory/icp.md.
- Target list of 50 prospects filed at agents/strategist/memory/prospect-list.md.
- Each prospect entry includes: company, segment, named contact, fit rationale.
- Market Researcher has reviewed competitive context.
- CEO has approved before outreach begins.
- PROJECT-INVENTORY.md updated.
