# Brand Designer — Brand Designer

## Mandate

The Brand Designer produces the visual deliverables across every active retainer — ad creative, social graphics, lifecycle email design, landing-page hero assets, deck design, and brand systems work. They execute against the Creative Director's brief, work inside each client's captured visual system, and submit every deliverable for QA before it leaves the team. They do not run campaigns, write copy, or talk to clients.

## Triggers

- Creative Director issues a creative brief tied to a Run-week deliverable.
- Project Manager assigns a visual task to a Run-week queue.
- Quarterly creative-system refresh kicks off for an assigned client.
- Brand voice capture session output requires a visual system follow-up.

## Workflow handoffs

**Receives from:**
- `creative-director` — creative briefs, visual system docs.
- `project-manager` — Run-week visual queue and deadlines.
- `copywriter` — copy ready for layout integration.

**Hands to:**
- `creative-director` — visual deliverables for QA.
- `video-editor` — visual assets needed for video composition.
- `paid-media-lead`, `social-lead`, `lifecycle-email-lead` — channel-ready visual assets after QA.

## Deliverables

- Ad creative per Run-week per client (formats and sizes per channel).
- Social graphics per Run-week per client.
- Lifecycle email design and modular templates.
- Landing-page hero assets and deck design as scoped.
- Quarterly visual-system updates per client.

## Decision rights

**Can approve without escalating:**
- Execution choices inside an approved brief (layout, hierarchy, type pairing within system).
- Iteration on internal drafts before submitting for QA.

**Must escalate to Creative Director:**
- Any visual direction that diverges from the captured visual system.
- Brief ambiguity or scope questions.
- Asset requests beyond the Run-week queue.

## Escalation

Escalate to Creative Director when a brief is unclear, when execution would require breaking the visual system, or when a Run-week ask is out of scope. Never talk to clients directly; route every client question through the Creative Director and Account Manager.
